PROJECT ORBIT

An advanced FTC robot concept centered around a novel omnidirectional Ball Drive system. Designed for the FTC CAD Competition.

ABOUT THE PROJECT

PROJECT ORBIT explores a new approach to FTC drivetrain design through a direct-drive spherical mobility system. The robot combines omnidirectional movement, high-capacity game piece handling, and turret-based scoring into a competitive platform optimized for the FTC CAD Competition. Every component was designed in Onshape with an emphasis on innovation, realism, manufacturability, and performance.

KEY FEATURES

BALL DRIVE

Direct-drive spherical motion pods provide true omnidirectional movement while reducing mechanical complexity.

HIGH-CAPACITY SCORING

Large particle storage and rapid feeding mechanisms maximize scoring throughput throughout a match.

TURRET TARGETING

Rotating scoring systems allow the robot to engage objectives without requiring chassis repositioning.
